> 基于 OpenGL 的消息式 2D 轻量化游戏引擎

---

## 特性

- ✅ 消息式绘图架构（逻辑/渲染线程解耦）
- ✅ OpenGL 后端，跨平台准备
- ✅ 纹理管理（创建/加载/删除）
- ✅ 绘图原语：点、线、矩形、三角形
- ✅ 纹理变换：旋转、UV裁剪、四点透视
- ✅ 序列帧动画系统
- ✅ 内置默认字体（ASCII）
- ✅ 实体系统（Hash 查找）
- ✅ 按钮控件
- ✅ 多线程消息队列
- ✅ 兼容 1.x API 模式（可选）
